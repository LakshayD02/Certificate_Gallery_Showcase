# Professional Certifications & LOR Showcase 🎓

A modern, high-performance, and visually captivating portfolio showcasing **100+ Professional Certifications, Cybersecurity Accreditations, and Letters of Recommendation (LORs)**. Built with modern HTML5, CSS3, and vanilla JavaScript.

---

## ✨ Key Features

- **🎨 Modern Glassmorphism & Cyber Aesthetics**:
  - Gradient typography, frosted glass sticky header, and radial ambient lighting.
  - Interactive dark theme (default) and clean ivory light theme with persistent preference storage.
- **⚡ Instant Real-Time Search & Live Filtering**:
  - Search across all 100+ credentials by title, issuer, or keyword (press `/` to focus instantly).
  - Dynamic category chips (`Cybersecurity`, `Cloud & DevOps`, `Web & Software`, `Data & AI`, `Coding & Problems`, `Hackathons`).
- **📊 Interactive Metrics Dashboard**:
  - Highlight cards summarizing key domains (36+ Cybersecurity, 5+ Cloud/DevOps, 40+ Software/Algorithms, 20 LORs).
- **🗂️ Dual Mode Switcher**:
  - Seamlessly switch between **Certificates (84)** and **Letters of Recommendation (20)** with animated counters.
- **🖼️ Cinematic Lightbox Viewer**:
  - Header with title, issuer badge, and sequence counter (`e.g., 14 / 84`).
  - Next / Previous buttons, keyboard arrow navigation (`←`, `→`, `Esc`), and mobile swipe gestures.
  - Click-to-zoom feature and one-click certificate download button with instant visual feedback.
- **🚀 High Performance**:
  - Shimmer placeholders for smooth image loading with zero layout shift (CLS).
  - Efficient lazy loading using Intersection Observer.
  - Floating back-to-top button.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic structure, ARIA accessibility attributes, and preconnected Google Fonts (`Plus Jakarta Sans`, `Outfit`, `JetBrains Mono`).
- **CSS3**: Custom design tokens, glassmorphism (`backdrop-filter`), CSS Grid & Flexbox, smooth cubic-bezier transitions.
- **Vanilla JavaScript**: Lightweight, zero-dependency search engine, dynamic categorizer, modal carousel, and theme manager.
